# ImageZoomView — 图片缩放工具

一个功能完整的浏览器端图片缩放查看工具，支持缩放、旋转、翻转、导出等操作，所有变换均围绕图片中心原位进行，不会产生意外位移。

## 功能特性

- **自由缩放** — 鼠标滚轮以光标位置为锚点缩放，按钮以视图中心缩放，精确滑块支持 5%~5000%
- **拖拽平移** — 鼠标拖拽自由移动图片，触屏单指平移、双指缩放
- **旋转** — 左旋/右旋各 90°，围绕图片中心原位旋转
- **翻转** — 水平/垂直镜像翻转，围绕图片中心原位翻转
- **导出** — 按当前缩放比例导出 PNG/JPEG/WEBP，支持质量控制，含旋转和翻转
- **小地图** — 右下角实时显示可视区域在整图中的位置
- **坐标追踪** — 底部状态栏实时显示鼠标在图片上的像素坐标
- **全屏模式** — 一键进入浏览器全屏

## 操作说明

### 鼠标

| 操作 | 说明 |
|------|------|
| 滚轮 | 以光标位置为锚点缩放 |
| 左键拖拽 | 平移图片 |
| 双击 | 在"适应窗口"和"实际大小"之间切换 |

### 触屏

| 操作 | 说明 |
|------|------|
| 单指滑动 | 平移图片 |
| 双指捏合 | 以双指中心为锚点缩放 |

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `+` / `=` | 放大 25% |
| `-` | 缩小 20% |
| `F` | 适应窗口 |
| `1` | 实际大小 (100%) |
| `O` | 打开文件 |
| `R` | 重置所有变换 |
| `Esc` | 关闭弹出面板 |

### 工具栏

左侧工具栏从上到下依次为：

1. **打开图片** — 选择本地文件上传
2. **放大** — 以视图中心放大
3. **缩小** — 以视图中心缩小
4. **适应窗口** — 缩放至完整显示
5. **实际大小** — 恢复 100%
6. **精确缩放** — 弹出滑块面板，支持预设比例
7. **左旋 90°** — 逆时针旋转
8. **右旋 90°** — 顺时针旋转
9. **水平翻转** — 左右镜像
10. **垂直翻转** — 上下镜像
11. **导出图片** — 弹出导出设置面板
12. **全屏** — 切换全屏模式

每个按钮悬停时会显示功能名称、操作说明和快捷键提示。

## 导出设置

点击导出按钮后可配置：

- **输出格式** — PNG（无损透明）、JPEG（有损压缩）、WEBP
- **压缩质量** — 选择 JPEG/WEBP 时可调节 10%~100%
- **输出尺寸** — 实时显示 `原始尺寸 × 当前缩放比例` 的像素尺寸及预估文件大小
- **安全限制** — 单边超过 16000px 时拒绝导出，防止浏览器崩溃

导出内容完整包含当前的缩放、旋转和翻转状态。

## 技术实现

### 坐标模型

采用**中心点定位模型**，CSS `transform-origin: 50% 50%`，变换链为：

```
translate(cx, cy) → translate(-50%, -50%) → scale(flipH×s, flipV×s) → rotate(deg)
```

所有旋转、翻转、缩放都围绕图片自身中心进行，不产生位移。

### 关键技术点

- **锚点缩放** — 通过缩放前后中心坐标的线性关系计算新位置，保持锚点不动
- **触摸缩放** — 计算双指距离比值，以双指中点为锚点
- **离屏导出** — 使用 Canvas 2D API 复现完整的变换矩阵，通过 `toBlob` 生成文件
- **小地图** — 根据当前视口与图片边界的交集计算可视区域比例

### 文件结构

npx serve .
```

然后访问 `http://localhost:8080`。
